# Global Generation - Генератор персональных планов

## Назначение

Приложение генерирует персональные PDF-планы работы для клиентов Global Generation после консультации. Менеджер предоставляет данные клиента, Claude формирует JSON, скрипт генерирует двухстраничный PDF в фирменном стиле GG.

Документ называется **«КП»** (коммерческое предложение). Дефолтное имя выходного файла - `output/КП для <имя>.pdf`.

## Процесс работы

1. Менеджер вставляет заметки с консультации (имя, направление, бюджет, сильные стороны, цели)
2. Claude генерирует JSON со всеми полями для шаблона
3. JSON сохраняется в файл (например `input.json`)
4. Запуск генерации: `.venv/bin/python generate_workplan.py input.json`
5. PDF появляется в папке `output/`

## Команда генерации

```bash
.venv/bin/python generate_workplan.py input.json
.venv/bin/python generate_workplan.py input.json --output custom_name.pdf
```

### Логика подбора ментора

- По направлению клиента (наука → Яра/Рената, спорт → Саша, творчество → Кристина/Алиса)
- По стране и уровню (США бакалавриат → Алёна/Саша, Англия/магистратура → Яра)
- По бюджету (бюджет $10K+ → Яра)
- Поле `why` — персональное объяснение почему ментор подходит именно этому клиенту

## Логика рекомендации формата

Рекомендация зависит от бюджета, сроков и сложности кейса:

- **Курс «Самостоятельное поступление»** (29 999 ₽ разово) — для клиентов с ограниченным бюджетом или простыми кейсами
- **Частичное менторство** (59 500 ₽/мес) — для клиентов, которые могут работать самостоятельно, но нужна стратегия
- **Полное менторство** (86 500 ₽/мес) — основная рекомендация для большинства клиентов, гарантия поступления (от 8 мес.)
- **Премиум менторство** (по запросу) — для сложных кейсов, нескольких стран, коротких сроков

В большинстве случаев рекомендуй **Полное менторство** — это основной продукт GG.

## Правила тона и стиля

- **Без длинных тире** (—) в тексте. Используй короткие тире (-) или перестрой предложение
- **Тёплое, персональное обращение.** Приветствие должно быть тёплым: "Мы были рады познакомиться с вами"
- **"Произвели на нас впечатление"** — обязательная фраза в приветствии, показывающая что клиента заметили
- **Без описания кто клиент.** Клиент знает кто он. Не нужен блок "о клиенте". Вместо этого — тёплое приветствие
- **Персонализация.** Каждый план должен чувствоваться уникальным, не шаблонным
- **Strengths и growth_areas** — по 3 штуки каждый
- **Work_plan** — 3-4 фазы, основанные на реальных этапах работы GG
- **Timeline в фазах** — только короткие формы: «Май-июнь 2026», «Июль-сен 2026», «Окт-дек 2026», «Янв-апр 2027». Длинные формы типа «Июль - сентябрь 2026» ломают плашку таймлайна на 3 строки и создают большой отступ между заголовком фазы и пунктами
- **client_name_genitive** — родительный падеж имени клиента для корректного имени файла «КП для <Имя>.pdf». Если поле не задано, используется client_name (может звучать неестественно: «КП для Артём» вместо «КП для Артёма»)

## PDF для родителей

Статичный документ (без переменных) для отправки родителям клиентов. Один PDF на всех, не нужно перегенерировать.

- **Шаблон:** `templates/parents.html`
- **Генерация:** `.venv/bin/python generate_parents.py`
- **Результат:** `output/GG_Для_родителей.pdf` + копия в `для_менеджеров/`
- **Содержание:** О компании, почему образование за рубежом, процесс работы, помесячная оплата, форматы/цены, гарантии, роль родителя, способы оплаты, контакты

## Гайд по поступлению за рубеж

Статичный документ (без переменных) для "нулевых" клиентов - тех, кто только начинает интересоваться поступлением. Отправляется как первый контакт для низкого сегмента. Универсальный гайд: США + Европа, ~3 страницы A4.

- **Шаблон:** `templates/guide.html`
- **Генерация:** `.venv/bin/python generate_guide.py`
- **Результат:** `output/GG_Гайд_по_поступлению.pdf` + копия в `для_менеджеров/`
- **Тон:** дружелюбный, простой, для студента 16-22 лет (не для родителя)
- **Содержание:** О GG, зачем учиться за рубежом, поступление в США и Европу, документы, стипендии, портфолио, форматы работы, гарантии, промокод WELCOME10
- **Промокод:** WELCOME10 - 10% скидка на курс "Самостоятельное поступление"

## Ответы на вопросы клиента (QA Response)

Персональный PDF с ответами на конкретные вопросы после консультации. Используется когда клиент задал вопросы, а не когда нужно продать — **без блока ментора, без цен, без призыва к действию**.

- **Шаблон:** `templates/qa_response.html`
- **Генерация:** `.venv/bin/python generate_qa_response.py case_xxx_qa.json`
- **Результат:** `output/Ответы для <Имя>.pdf`
- **Структура JSON:** `client_name`, `client_name_genitive`, `date`, `greeting_text` (можно пустым), `sections[]`
- **Секция:** `question` (заголовок), `intro` (опционально), `subblocks[]` (с `title` и `points[]`), `note` (опционально)
- **Важно:** поле называется `points`, не `items` (конфликт с dict.items() в Jinja2)
- **Пример:** `case_irina_qa.json` (Кира, Business Analytics, Италия/Австрия/США, бюджет $8K)
