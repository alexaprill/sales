# Roadmap KP Generator

Самостоятельный генератор подробного коммерческого предложения - «Дорожная карта и смета».

Используется для клиентов, которым нужна **операционная детализация**: таймлайн с датами, смета расходов (подготовка + менторство + tuition с aid), риски, блок ответов на возражения. Не связан с основным приложением GG.

## Структура документа (2-4 страницы A4)

1. **Таймлайн подготовки** - периоды, задачи, deliverables, ответственный (обязательно)
2. **Смета проекта** - три блока: расходы на подготовку, менторство GG, tuition с aid и net cost (обязательно)
3. **Риски и митигация** - таблица вероятностей и плана действий (опционально, `risks`)
4. **К вашим вопросам** - блок ответов на возражения клиента, closing note (опционально, `qa_block`)

## Использование

```bash
# Зависимости (если нет)
pip install jinja2 weasyprint

# Генерация
python generate_roadmap.py case_example.json

# → output/roadmap_<имя>_<дата>.pdf
```

Или с кастомным именем:

```bash
python generate_roadmap.py case_example.json --output my_custom.pdf
```

## Структура JSON

Обязательные поля: `client_name`, `timeline`, `cost_preparation`, `cost_mentorship`, `cost_tuition`, `totals`.

Опциональные: `intro_text`, `risks`, `qa_block`, `disclaimer_timeline`, `date`.

См. `case_example.json` - полный рабочий пример со всеми полями.

### Гибкость по цифрам

- `cost_mentorship.months` и `total_rub` можно передавать как число или как строку-диапазон (например `"6-12"` и `"510 000 - 1 020 000"`).
- `cost_tuition[].range_low_usd` может быть отрицательным (для aid как вычета) - шаблон отрендерит как `-$40,000`.
- `cost_tuition[].highlight: true` подсвечивает ключевую строку (обычно net cost).

## Фирменный стиль

- Шрифт: Mulish
- Цвета: Navy `#12284C`, Cyan `#00C1DE`, Blue `#407BFF`
- A4, встроенный watermark-логотип

## Правила тона

- Без длинных тире (—), только короткие (-)
- Без эмодзи
- Таблицы сухие и точные - операционный документ, не маркетинговый
- Цифры с разделителями тысяч (1 000 000 ₽, $60,000)
- Диапазоны там, где есть неопределённость (tuition, aid)
